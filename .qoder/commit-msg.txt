refactor: move MySQL auth utilities to protocol/mysql/auth/

Move 4 pure utility files from common/util/ to protocol/mysql/auth/:
- SecurityUtil: SHA-1/SHA-256 scramble, XOR, RSA operations
- MysqlNativePasswordPluginUtil: mysql_native_password auth plugin
- RandomUtil: random byte generation (only used by auth code)
- MySQLUtil: fix-int byte array conversion (currently unused)

These files had zero dependencies on common module classes, making them
safe to move. CachingSha2PasswordPlugin stays in common (depends on
MycatException, MycatRowMetaData) and now imports SecurityUtil from
protocol.
